# Projeto de Análise de Dados de Recursos Humanos (RH)

Este repositório contém um projeto prático de Análise Exploratória de Dados (EDA) aplicado ao setor de Recursos Humanos, desenvolvido com o objetivo de analisar distribuições salariais, jornadas de trabalho e correlações entre variáveis corporativas.

## 🛠️ Tecnologias e Ferramentas Utilizadas
* **Python 3.10+**
* **Pandas** (Manipulação e estruturação de dados)
* **Matplotlib & Seaborn** (Visualização gráfica e Boxplots)
* **Sweetviz** (Geração de relatórios exploratórios automatizados)
* **YData Profiling** (Análise estatística aprofundada)
* **Git & GitHub** (Controle de versão e gestão por branches)

---

## 📂 Estrutura do Projeto e Branches
O projeto foi desenvolvido seguindo boas práticas de versionamento com Git, dividindo as etapas em *branches* específicas:
1. **`main`**: Branch principal com a estrutura base do projeto e documentação.
2. **`exercicio-1-boxplot`**: Focada na análise visual de salários por departamento através de gráficos de Boxplot e extração da tabela de medianas.
3. **`exercicio-2-sweetviz`**: Focada na criação e exportação do relatório exploratório em HTML (`relatorio_rh_sweetviz.html`).
4. **`exercicio-3-ydata`**: Focada no relatório estatístico detalhado de qualidade de dados (`relatorio_rh_ydata.html`).

---

## 📊 Principais Análises Realizadas
* **Boxplot de Salários:** Identificação visual da mediana salarial e detecção de *outliers* por departamento.
* **Métricas Estatísticas:** Avaliação de valores distintos, tratamento de registros históricos/múltiplos lançamentos por colaborador e verificação de integridade dos dados.
* **Relatórios Automatizados:** Geração de painéis interativos em HTML para apresentação executiva à gerência de RH.
